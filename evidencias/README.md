# Evidências de produção

O workflow `k6 production` e a execução local documentada em `k6/README.md`
gravam nesta pasta o arquivo `k6-qualeider-summary.json`.

O JSON contém contagem de requisições, taxa de falhas, latências, checks,
thresholds e duração do teste. O arquivo gerado não deve ser editado: ele é a
evidência bruta da execução.
